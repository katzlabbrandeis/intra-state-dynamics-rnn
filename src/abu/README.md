## Extracting Data

### Changepoints

Located under `src/core/utils/unpkl_generator.py`:

- **`extract_valid_changepoints`**: Generates changepoints from the single legacy file (`changepoints.pkl`)
- **`unpkl_changepoints`**: Feed this the `output/intermediate_data/changepoints/` directory found in:
  - `RNN_PROCESSING_PARQUETS`
  - `PRED_FR_RNN`
  - `FR_PROCESSING_PARQUETS`
  - `PKL_CACHE`
  
  (All contain the same changepoint data)

### Firing Rates and Latents

**Note**: This is where the file organization finally became consistent!

#### General Overview

- **`JULY_RNN_RUN`**: Model run from July when we realized we needed inferred firing rates
- **Everything else**: Original October run used for the thesis (with good latents)

#### RNNLatentprocessing Schema

All directories "generated by RNNLatentprocessing" follow this naming convention (see `/src/core/pre_processing/RNNLatentprocessing.py`):

**Directory Name Keywords:**

- **`_warped`**: Interpolation used to warp all states to same length across trials for a given taste
- **`_unwarped`**: Data unmolested by interpolation
- **`raw_output`** or **`epoch_dataframes`**: Un-PCA'd latents/firing rate vectors
  - *Note*: `epoch_dataframes` is a legacy name; both should contain the same data
- **`robust_pca_95`**: Latents/FR vectors after PCA, keeping 95% of variance
  - **This is what you want for latents**
  - "robust_pca" = all trials concatenated → PCA applied → de-concatenated per taste
- **`robust_pca_full`**: Same as `robust_pca_95`, but keeping 100% of variance
- **`first_derivatives`**: First difference of the given vector
- **`second_derivatives`**: Second difference of the given vector
- **`changepoints`**: Changepoints (see above for access methods)
- **`ttest`**: Mann-Whitney U test between vectors for first half/second half split to determine if vector is "dynamic"
  - See line 1039 in `RNNLatentprocessing.py` for details

#### Reading Parquet Files

**In all cases**, use:
```python
df = pl.read_parquet()  # Read parquet file(s)
df.schema()             # Get schema
df.filter(pl.col('col_name'))  # Filter by column
df['col'].unique()      # Get unique values
```

**Helper functions** in `/src/core/utils/read_parquets.py`:
- Read parquets into dict of Polars DataFrames
- Read everything into one mega DataFrame

### Data Directory Structure

#### FR_PROCESSING_PARQUETS
**Location**: `/output/intermediate_files/FR_PROCESSING_PARQUETS`

Analysis involving convolved firing rates (inferred from spike trains):

- **`rr_firing_uw_lite_rnn_outputs`** ⭐ **START HERE**
  - Sub-directories generated by RNNLatentprocessor
  - This is probably where you want to pull data from
- **`spike_trains`**: Spike trains in parquet form
- **`rr_firing_uw_lite_cleaned`**: Rolling window firing rates with schema fixes and cleanup
  - Usable data, though not the most useful
- **`rr_firing_uw_lite`**: ❌ Unclean data, don't use (being phased out)
- **`rr_firing_unwarped`**: ❌ Don't use; go to `rr_firing_uw_lite_cleaned` instead
- **`spikes_warped`**: Interpolated spikes (unclear why this was attempted)
- **`spikes_unwarped`**: Unmolested spike train vectors
  - *Note*: Unclear how this differs from `spike_trains`; will update
- **`changepoints`**: Changepoints

#### RNN_PROCESSING_PARQUETS
**RNN data from the thesis**

ALL data here generated by RNNLatentprocessor (schema above applies in full)

#### PRED_FR_RNN
**RNN predicted firing rates from July run**

All data generated by RNNLatentprocessor

#### JULY_RNN_RUN
**July run data**

Contains its own:
- `PRED_FR_RNN`
- `RNN_PROCESSING_PARQUETS`

Data specific to that run; both generated by RNNLatentprocessor
