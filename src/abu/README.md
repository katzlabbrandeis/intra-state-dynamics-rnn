#### RNNLatentprocessing Schema

All directories "generated by RNNLatentprocessing" follow this naming convention (see `/src/core/pre_processing/RNNLatentprocessing.py`):

**Directory Name Keywords:**

- **`_warped`**: Interpolation used to warp all states to same length across trials for a given taste
- **`_unwarped`**: Data unmolested by interpolation
- **`raw_output`** or **`epoch_dataframes`**: Un-PCA'd latents/firing rate vectors
  - *Note*: `epoch_dataframes` is a legacy name; both should contain the same data
- **`robust_pca_95`**: Latents/FR vectors after PCA, keeping 95% of variance
  - **This is what you want for latents**
  - "robust_pca" = all trials concatenated → PCA applied → de-concatenated per taste
- **`robust_pca_full`**: Same as `robust_pca_95`, but keeping 100% of variance
- **`first_derivatives`**: First difference of the given vector
- **`second_derivatives`**: Second difference of the given vector
- **`changepoints`**: Changepoints (see above for access methods)
- **`ttest`**: Mann-Whitney U test between vectors for first half/second half split to determine if vector is "dynamic"
  - See line 1039 in `RNNLatentprocessing.py` for details

#### Reading Parquet Files

**In all cases**, use:
```python
df = pl.read_parquet()  # Read parquet file(s)
df.schema()             # Get schema
df.filter(pl.col('col_name'))  # Filter by column
df['col'].unique()      # Get unique values
```

**Helper functions** in `/src/core/utils/read_parquets.py`:
- Read parquets into dict of Polars DataFrames
- Read everything into one mega DataFrame
